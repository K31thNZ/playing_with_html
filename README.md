# Moscow Adult Activity Club

A static voting and calendar page for an English-language activities club in Moscow.

## Features
- ❤️ Vote for your favourite activities (saved in browser localStorage)
- 🕵️ Social deduction games section (Mafia, Werewolf, Avalon, Spyfall, Blood on the Clocktower)
- 📅 July–September 2026 event calendar
- 🏆 Live leaderboard
- Filter by category: Social / Social Deduction / Culture / Active / Creative

## Deploying on Render

1. Push this repo to GitHub (or GitLab)
2. Go to [render.com](https://render.com) → New → Static Site
3. Connect your repo
4. Set **Publish directory** to `.` (root)
5. Leave **Build command** blank
6. Click **Create Static Site**

Render will auto-deploy on every push to `main`.
